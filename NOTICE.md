# Project Provenance and Scope

This repository is a GitHub fork of the official
[`HKUSTDial/kddcup2026-data-agents-starter-kit`](https://github.com/HKUSTDial/kddcup2026-data-agents-starter-kit)
for KDD Cup 2026 DataAgent-Bench. The upstream starter kit, competition name, datasets,
documentation, and visual assets remain attributable to their respective authors and organizers.

The personal work in this fork is limited to `PHASE_1` and focuses on:

- local evaluation and reproducible experiment reporting;
- request, task-process, and Python-process lifecycle reliability;
- OpenAI-compatible native tool calling and strict argument validation;
- bounded context exploration and conservative answer projection;
- deterministic answer verification and step-budget finalization;
- an opt-in Evidence Plan protocol and its ablation results.

`PHASE_2` is not part of the personal implementation work and remains the upstream baseline.

This notice documents provenance; it does not grant, replace, or reinterpret a software license.
Refer to the upstream repositories and competition rules for the permissions applicable to their
materials.

# 项目来源与范围

本仓库是 KDD Cup 2026 DataAgent-Bench 官方
[`HKUSTDial/kddcup2026-data-agents-starter-kit`](https://github.com/HKUSTDial/kddcup2026-data-agents-starter-kit)

参数校验、有界 Explorer、确定性答案校验、步数收尾守卫，以及可选 Evidence Plan 协议和
对应消融实验。`PHASE_2` 未纳入个人实现范围，保持官方基线。
